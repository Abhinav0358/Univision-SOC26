# SOC26 Study & Implementation Repository

This repository contains notes, code implementations compiled during the project.

## Repository Structure

* **`notes.md`**: notes covering the anomaly detection pipeline, frontend development (Vite, TypeScript, Zustand), and backend testing (Pytest).
* **`ds/`**: Python implementations and labs covering core Data Science concepts (data cleaning, regression, tree ensembles, dimensionality reduction, clustering, and NLP) as a revision of DS203.
* **`opencv/`**: Computer vision basics and pipelines (filtering, edge detection, object detection with YOLO, OCR via Tesseract, and object tracking).
* **`kahns.cpp`**: C++ implementation of topological sorting using Kahn's Algorithm.

## Progress Summary

A overview of the topics covered and implemented so far:
* Frontend: Vite, TypeScript, Zustand, React Flow setup, Google Blockly.
* Testing: Isolated unit tests using Pytest.
* Systems: Background automation using Node-RED.
* Algorithms: Topological sorting for workflow DAGs.
* OpenCV: Image pre-filtering, basic enhancements, object detection, OCR reading, and centroid-based object tracking.
* Data Science: Feature encoding, scaling, statistical significance tests, optimization methods, regression evaluation, classification metrics, tree ensembles, clustering, and simple NLP pipelines.
